Installer Orkel-ioT sur un ESP32

  1. Ordinateur avec Chrome ou Edge, ESP32 branché en USB avec un câble de données.
  2. Choisir la version et la carte ci-dessous, cliquer sur Installer, choisir le port de l'ESP32, confirmer.
  3. Après l'installation : Wi-Fi Orkel-ioT-Setup, puis http://192.168.4.1/ → Système → Wi-Fi.
Navigateur non compatible : utilise Chrome ou Edge sur un ordinateur. Ouvre cette page en https (GitHub Pages).

L'installation par câble efface tout le module, réglages compris. Pour mettre à jour un module qui marche déjà, utilise plutôt la mise à jour sans câble (page Système d'Orkel-ioT) : les réglages sont gardés.

« Choix automatique » : la page reconnaît seule l'ESP32 classique ou l'ESP32-S3 (version universelle 4 Mo, qui fonctionne aussi sur les cartes 8 Mo). Les mises à jour suivantes se font sans câble, avec les fichiers OTA_… des Releases : la page Système d'Orkel-ioT indique lequel prendre.
