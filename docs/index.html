2

Brancher et installer

  1. Ordinateur avec Chrome ou Edge, carte branchée en USB avec un câble de données (pas un simple câble de charge).
  2. Cliquer sur Installer, choisir le port de la carte, confirmer. Compter 1 à 2 minutes.
Choisis d'abord ta carte (étape 1).
Navigateur non compatible : utilise Chrome ou Edge sur un ordinateur. Ouvre cette page en https (GitHub Pages).
Version :

L'installation par câble efface tout le module, réglages compris. Pour mettre à jour un module qui marche déjà, utilise plutôt la mise à jour sans câble (page Système d'Orkel-ioT) : les réglages sont gardés.

3

Premier démarrage

  1. Sur le téléphone, se connecter au Wi-Fi Orkel-ioT-Setup, puis ouvrir http://192.168.4.1/.
  2. Page Système → Wi-Fi : nom et mot de passe de la box (2,4 GHz), Enregistrer.
  3. Revenir sur la box et ouvrir http://orkel-iot.local/ (ou l'adresse affichée). Orkel-ioT démarre en mode simulation : il ne commande rien tant que tu ne l'as pas coupé. Suivre le guide.

Les mises à jour suivantes se font sans câble, depuis la page Système (bouton GitHub ou fichier OTA_… des Releases).
